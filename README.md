I study **electrical and energy engineering at EHTP**. I work on fault detection in grids and electrolyzers, experiment with wireless power transfer, and explore embedded systems and industrial cybersecurity.

### Work

| Project | What I'm working on |
| :--- | :--- |
| **cascade-gnn** | Cascading grid failures using **PowerGraph**, **PyTorch Geometric**, and an **XGBoost** baseline. Model inspection with GNNExplainer; results in Streamlit. |
| **PEM diagnostics** | A student competition project exploring **MCSA-inspired current analysis** for electrolyzer faults, with **XGBoost** and **SHAP**. |
| **Resonant WPT** | A TIPE prototype reaching **23% efficiency at 34 kHz**, with **R² = 0.992** in a model comparison against the Yates reference. |
| **OT / SCADA** | An anomaly-detection dashboard in development. |
